Add a **Split episodes** workflow to Organize. Select one or more TV rows and open the split editor to estimate cut points from TVDB episode runtimes (leftover runtime is spread evenly across the cuts), scrub a filmstrip of sampled frames to find title cards, nudge cuts against video keyframes, and assign or auto-match an episode to each segment. Splits are queued with the normal renames and apply together in one background job with a live progress bar and cancellation; stream-copy cuts are lossless by default, with an optional frame-exact re-encode. The original file can be backed up, deleted or kept per split, external text subtitles can be cut per segment, Plex parts are updated per episode, and Undo removes the split outputs and subtitle files and restores a backed-up original with its subtitles.

The app now bundles `ffmpeg-static` and uses the resolved binary for FFmpeg conversions as well as splitting; Settings → Global can point at a custom executable. Library organizer settings gain defaults for the split editor (original-file policy, cut mode, subtitle sidecars and split concurrency).

The split editor preview shows the exact frame at the playhead while scrubbing or dragging a cut. Copy mode previews the frame each cut will actually land on, marks the five nearest alternative keyframes on the strip so a better split point is one click away, and a **Center on split** button recenters the pan. Copy cuts now use the keyframe chosen in the editor and normalize by the first video frame's timestamp, so the dotted landing line matches the timestamp ffmpeg actually cuts at. **Split file** is available on every TV row and **Split files** works on any TV selection, so a file whose episodes are non-contiguous in TVDB can still be separated: single-episode files open a two-segment plan, and cuts can be added at the playhead, snapped to the nearest all-black run, or generated for every black gap. Both black-frame tools also run across every file at once, one scan at a time, with a combined progress bar and ETA; files already scanned reuse their result. The single-file scan streams ffmpeg progress into a percentage on the button and a progress bar, since scanning a whole file can take a while. Controls explain themselves on hover or keyboard focus instead of carrying a separate info icon. Each segment's quick episode list is limited to the file's detected range, and **Select other episode** opens the shared **Fix match** dialog. A split must be approved — individually or with **Approve all** — before **Save approved** writes it; unapproved edits are discarded while an already-queued split stays queued. An adjusted split carries a pending marker and reads **ready for review**, and an approved split is outlined in green.
